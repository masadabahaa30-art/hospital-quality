# نظام إدارة جودة المستشفيات (Hospital Quality Management System)

## نبذة عن المشروع
نظام ذكي تم تطويره باستخدام Python و Streamlit لتحليل بيانات الجودة وسلامة المرضى داخل المستشفيات. يتيح النظام للمتخصصين رفع تقارير الجودة (Excel) والحصول على تحليل بياني فوري لدعم اتخاذ القرار.

## المميزات
- **تحليل تلقائي**: معالجة بيانات الجودة واستخراج مؤشرات الأداء.
- **عرض بياني**: رسم توضيحي للبيانات لسهولة متابعة التحسينات.
- **سهولة الاستخدام**: تصميم واجهة بسيطة وتفاعلية.

## التقنيات المستخدمة
- Python (Pandas)
- Streamlit
- GitHub & Streamlit Cloud

## عن المطورة
أنا **Mayada Bahaa**، أخصائية تغذية مهتمة بتحليل البيانات وإدارة الجودة (Quality Management) وسلامة الغذاء. أهدف لدمج الحلول البرمجية الذكية لتحسين الأداء داخل المنشآت الطبية والغذائية.
